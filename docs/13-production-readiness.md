# 13 — Production Readiness

Before converting to a government hazard system:

- [ ] Official building footprints
- [ ] Digital elevation model
- [ ] Flood hazard maps and drainage layers
- [ ] Official fault-line datasets
- [ ] Soil and liquefaction data
- [ ] Historical flood records
- [ ] Structural building information
- [ ] Validated earthquake models
- [ ] Barangay boundaries (official)
- [ ] Scientific review by qualified agencies
- [ ] Clear distinction: visualization vs official advisories

Current prototype status: **Demonstration UI only — not production-ready.**
