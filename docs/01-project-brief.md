# 01 — Project Brief

**Project Name:** Lasam Urban Hazard Planning and Simulation Prototype

**Primary Objective:** Create a browser-based map interface for demonstrating flood, earthquake, and fault-line exposure in selected areas of Lasam, Cagayan.

**Prototype Type:** Frontend-only interactive demonstration.

**Target Users:** MPDC, Municipal Engineering, MDRRMO, Mayor and officials, Barangay officials, GIS staff.

**Limitations:** No login, database, official hazard calculation, or real-time feeds. Building data uses samples. Clear demo disclaimer required.

**Timeline:** 6–8 working days across 5 implementation phases.
