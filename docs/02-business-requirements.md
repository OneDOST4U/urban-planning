# 02 — Business Requirements

## Problem

Lasam urban planners need a visual platform to demonstrate flood exposure, fault proximity, and earthquake effects during meetings with LGU stakeholders.

## Goals

1. Replace static maps with an interactive 3D-style demonstration
2. Allow hazard scenarios to be controlled with sliders and buttons
3. Show affected building counts in real time
4. Support presentation to mayor, MPDC, MDRRMO, engineering, and barangays

## Non-Goals (Prototype)

- Scientific flood or earthquake modeling
- Official hazard advisories
- User authentication or data persistence
