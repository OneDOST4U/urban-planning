# 06 — UI/UX Specification

## Layout

- **Header:** Title, 2D/3D toggle, reset, fullscreen
- **Disclaimer banner:** Amber demo notice
- **Map area:** Full-screen MapLibre with floating toolbar
- **Right sidebar:** Hazard panel tabs (Flood, Quake, Fault, Layers)
- **Bottom bar:** Stats, play/pause, speed, current value

## Map Toolbar

Select, Pan, Draw Fault, Epicenter, Measure, Zoom Home, Clear

## Color Schemes

### Flood Exposure
Gray → Yellow → Orange → Red → Dark Red

### Earthquake Damage
Green → Yellow → Orange → Red → Dark Red

## Inspiration

Project NOAH-inspired layout (control panel, legend, simulation bar) without copying branding.
