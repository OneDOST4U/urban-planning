# 05 — User Stories

1. **Flood Simulation** — As an urban planner, I want to adjust simulated flood level to identify potentially affected houses.
2. **Earthquake Simulation** — As an MDRRMO officer, I want to place an epicenter and adjust magnitude to demonstrate impact zones.
3. **Fault-Line Mapping** — As GIS staff, I want to draw a fault line with a danger buffer to identify nearby buildings.
4. **Building Inspection** — As an engineer, I want to click a building to see hazard-exposure information.
5. **Presentation Mode** — As a municipal official, I want a dashboard for clear meeting presentations.
6. **Scenario Reset** — As a planner, I want to reset the map to demonstrate another scenario quickly.
